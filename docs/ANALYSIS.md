# 설치본 분석과 재구현 범위

## 분석 원칙

- 설치 경로 `C:\Users\samsung\AppData\Local\Programs\Workpets`는 읽기 전용 비교 대상으로 취급했다.
- 원본 실행 파일을 수정하거나 인증 정보, 사용자 데이터, 네트워크 요청을 실행하지 않았다.
- 재구현 프로젝트에는 원본 브랜드·이미지·서버 주소·라이선스 로직을 복사하지 않았다.
- 화면에서 확인 가능한 기능 흐름과 로컬 API 표면을 근거로 독립적인 구조를 설계했다.

## 확인된 기술 구조

- `Workpets.exe`와 `_internal/python312.dll`, 다수의 `.pyd`가 있어 Python 3.12/PyInstaller 계열 패키징으로 판단된다.
- `_internal/webview`에 WebView2와 pywebview 구성요소가 있다.
- `_internal/static/index.html` 및 여러 JavaScript 파일이 로컬 HTTP API를 호출한다.
- 핵심 실행 엔진은 CLI 에이전트 프로세스를 생성하고 카드 상태, 로그, 세션을 로컬 API로 제공하는 형태다.

## 원본에서 관찰한 핵심 기능군

1. 에이전트 프로필과 역할 관리
2. 작업 카드의 todo/running/review/done 흐름
3. CLI 프로세스 실행, 중지, 결과·대화 기록
4. 작업 폴더, 파일, 산출물 관리
5. 일정, 타임라인, 사용량 통계
6. 다중 계정 및 MCP 연결
7. 커뮤니티·게임화·원격 접속·업데이트·라이선스

## 현재 제약

- WindowsApps 별칭은 `Access is denied`였지만 `%LOCALAPPDATA%\OpenAI\Codex\bin`의 최신 버전 실행 파일을 자동 감지해 실제 종단 실행에 성공했다.
- Claude CLI는 현재 PATH에서 발견되지 않았다.
- Claude 전용 stream-json 세부 파서는 아직 없으며 일반 stdout/stderr로 표시한다.
- portable 앱은 자체 코드 서명 인증서가 없어 SmartScreen 경고가 나타날 수 있다.
