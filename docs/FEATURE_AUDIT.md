# v0.5 기능 감사

검토일: 2026-07-20 KST

## 이번 감사에서 발견하고 수정한 항목

| 영역 | 기존 상태 | v0.5 결과 |
|---|---|---|
| 역할 프리셋 | 새 에이전트 입력칸만 채우고 저장된 역할과 연결되지 않음 | 에이전트에 `presetId` 저장, 전용 역할 적용 API와 역할 지정·변경 화면 추가 |
| 기존 에이전트 역할 변경 | 세부 필드를 수동으로 다시 작성해야 함 | 이름·CLI 연결을 유지한 채 역할·기본 지시·색상을 한 번에 교체 |
| 역할 적용 확인 | 현재 어떤 프리셋인지 알 수 없음 | 에이전트 카드와 오피스 명단에 현재 프리셋 배지 표시 |
| 작업 시작 흐름 | 상세 작업은 만든 뒤 다시 실행해야 함 | `만든 뒤 바로 실행하기` 기본 옵션 추가 |
| 초기 설정 상태 | 빠진 설정을 사용자가 각 화면에서 추측해야 함 | 오피스에 작업 폴더·에이전트·역할·어댑터 4단계 준비 상태와 이동 버튼 추가 |
| 캔버스 접근성 | 캔버스 캐릭터 외에 명확한 에이전트 진입점이 부족함 | 캔버스 아래 클릭 가능한 에이전트 명단 추가 |
| 모달 닫기 | 필수 입력이 비어 있으면 닫기·취소까지 유효성 검사에 막힘 | 공통 닫기·취소 동작을 제출과 분리 |
| 역할 실행 연결 | 기본 역할 지시 저장 여부만 확인 | 저장된 역할 지시가 실제 작업 프롬프트 앞에 결합되는 기존 실행 테스트 유지 |

## 현재 완성된 핵심 흐름

1. 프로젝트 폴더를 등록한다.
2. 프리셋으로 에이전트를 만들거나 기존 에이전트에 역할을 지정한다.
3. 오피스 준비 상태가 `4/4`인지 확인한다.
4. 오피스 발사대 또는 상세 작업 모달에서 작업을 바로 실행한다.
5. 캐릭터·모니터·말풍선과 작업 보드에서 상태를 확인한다.
6. 검토 화면에서 결과·로그·산출물을 보고 완료 또는 후속 실행한다.

## 의도적으로 다음 버전으로 남긴 항목

다음은 v0.5의 개인용 로컬 에이전트 오피스 핵심 흐름을 막지 않으므로 후속 범위로 분리했다.

- 작업 카드 간 의존성 그래프와 다단계 파이프라인
- 칸반 드래그 앤 드롭과 예약 작업 편집·일시 정지 UI
- Claude stream-json 전용 구조화 파서
- 상태 파일 가져오기·내보내기와 자동 백업
- 캐릭터 외형·가구·방 테마 편집기
- 장기 로그 회전, 실패 재시도·백오프
- 코드 서명과 사용자 브랜드 아이콘
- 다중 사용자 공유, 인증, 외부 접속

원본의 결제, 라이선스, 업데이트, 텔레메트리, 피드백 전송, 원격 터널 기능은 누락이 아니라 의도적인 제외다.
