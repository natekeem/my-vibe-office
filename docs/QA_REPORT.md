## 외부 기능 제외 감사

실행 코드에는 원본 라이선스, 결제, 체크아웃, 피드백 전송, 텔레메트리, 앱 업데이트, Cloudflare 터널, 커뮤니티·랭킹·게임 경제 API가 없다. 서버는 기본적으로 `127.0.0.1`에만 바인딩된다.

Electron과 electron-builder는 개발·패키징 의존성이다. 실행 앱이 임의의 외부 서버로 사용자 작업 내용을 보내는 코드는 작성하지 않았다. 실제 Codex 또는 Claude CLI가 수행하는 네트워크 통신은 각 CLI의 설정과 서비스 정책에 따른다.

## 알려진 제약

- WindowsApps의 별칭은 `Access is denied`지만 앱이 동작 가능한 최신 `%LOCALAPPDATA%` Codex CLI를 자동 선택한다.
- Claude CLI는 PATH에서 발견되지 않았다.
- Codex JSONL은 구조화하지만 Claude stream-json 세부 이벤트 파서는 다음 버전 범위다.
- portable 파일은 코드 서명 인증서로 서명하지 않았으므로 Windows SmartScreen 경고가 나타날 수 있다.
- 기본 Electron 아이콘을 사용한다. 독립 브랜드 아이콘은 다음 디자인 단계에서 교체한다.
